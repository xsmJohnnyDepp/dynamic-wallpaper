# Event Horizon

## Source and original-art limits

This is an AI-generated original dynamic-wallpaper set inspired by the idea of an isolated experimental spacecraft, unknown gravity phenomena, and a deep-space rescue. It uses a restrained 1990s-style modular industrial science-fiction vocabulary: cold blue, graphite black, oxidized metal, and small amber or emergency-red light accents.

The set does not use film stills, actor likenesses, characters, dialogue, titles, logos, readable interface text, or a recognizable spacecraft design or shot composition. Every scene is an empty space: there are no people, spacesuit figures, bodies, blood, gore, or monsters. Its unease comes from empty scale, static machinery, lighting, and an abstract gravity anomaly.
