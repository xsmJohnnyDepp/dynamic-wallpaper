# 人物造型與產圖 brief（日後必讀）

身體界線、一次一度量、姿勢決定看不看得見：與 `images/kyoto/README.md` 同一套。京都那組是短裾和服；宇治午前是 OL 套裝。下襬、襪、鞋一樣用身體線寫，不要寫 `mini` / `再短 10cm` / 單獨 `5 denier`。

## 產圖提示：身體界線

```
ONE CHANGE: [delta].
The current [feature] [wrong landmark].
The new [feature] [success landmark].
Still [ceiling so it does not overshoot].
```

| 不要寫 | 要寫 |
|---|---|
| `mini` / `short skirt` | `8`：現在下襬在大腿中段、臀部全蓋住；新下襬露出臀部下弧，布料仍蓋住臀部上半 |

## 已驗證流程

1. 先 `cp --update=none N.jpg _trials/N-original.jpg`。
2. 產圖 `16:9`。場景用該小時原圖；**不要**把已放大的人物小時拿去當下一張的姿勢／尺度參考。
3. 一次一個可見度量。先寫參考圖哪裡不對，再寫新界線；有上限也有露出下限。
4. 寫入正式檔：

```bash
convert "$SRC" -filter Lanczos -resize '3840x2160^' -gravity center \
  -extent 3840x2160 -colorspace sRGB -quality 92 \
  "$DEST/_trials/${trial}.jpg"
cp "$DEST/_trials/${trial}.jpg" "$DEST/${hour}.jpg"
```
