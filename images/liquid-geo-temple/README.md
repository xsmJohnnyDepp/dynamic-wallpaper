**完整桌布試作解析度（2026-10-02）：至少 `1920×1080`。** 新的完整場景與人物試作以模型直接輸出 `2048×1152`、high 品質；不再用 `1280×720` 作為完整檢視稿，也不以單純放大舊圖充當新增細節。局部編修裁切、遮罩與縮小對照圖不受完整桌布尺寸限制。正式稿仍為 `3840×2160` sRGB JPG；尺寸驗收之外，也要檢視細節品質。

### 已接受的深化方向（2026-10-02）

**文明在過載時仍主動加碼：它清楚知道極限在哪裡，仍決定再往前一步。** 場景同時呈現巨大的失控力量與精確到令人不安的控制能力。

1. **建築暴露運作方式。** 從 16 起，霜銀牆板逐層離開原位，露出深處的六角承載節點；節點彼此沒有實體連接，卻仍把整片牆懸住。以可見的承載能力呈現外星高科技。
2. **一條粒子流串起五小時。** 延續 15 的地面導槽：16 逆流上升 → 17 分成不同重力方向 → 18 沿井壁往上湧 → 19 凝成新拱 → 20 全部被渦心拉回。讓各張讀得出同一套系統的演變。
3. **異常平靜的前景。** 巨大結構在中景扭轉，近處平台仍平整、明亮，邊緣接縫維持精準。這是文明刻意維持的觀測位置，也是後續人物選擇留下觀看的空間依據；先讓平台本身融入空景構圖。
4. **19 是一次驚人的反攻。** 重構幾何拱比原本更大、更不對稱，跨越兩個重力方向；短暫成立後才在 20 被吞回。五小時有推進與反攻的高峰。

**16 的第一槍構圖：** 核心偏離畫面中心，承載環被拉向斜上方，牆體與地板的受力線一起追過去；鏡頭仍站在平穩平台。第一眼就能感到整座廳正在承受超出設計尺度的力量。

### 場景共通判準

- **力量有形狀：** 粒子密度、板層位移、弧的彎曲與接縫張力，要讓重力運作看得見。
- **材質有重量：** 霜銀板、槍灰承重結構、霧黑六角碳粒子的厚度、斷面與投影都要可讀；粒子實體且不自發光。
- **每張一個強烈主事件：** 承載 → 多重重力 → 開井 → 重構 → 塌縮。事件之間有演變，不把所有異象同時塞滿每張。
- **明亮度服務空間：** 16–17 維持銀廳曝光；18–20 逐步加深核心，前景與承載面仍可讀。兩側保留低細節區域給桌面圖示。
- **外星技術由結構表現：** 建築與裝置共享六角材質語言；不加可讀 UI、螢幕、全息、霓虹或標誌。延續無血、傷口、火焰、怪物的既有約定。

## 不可拆的人物語法

**目錄式：** 每小時可以換臉、五官、髮、妝、服裝。`0`–`13` 鎖死的是短裾＋連褲襪美腿＋聖殿材質，不是同一張臉。`14`–`20` 改鎖「協議失效」：支撐線逐小時鬆掉，見下節。不仿可辨識藝人。

### 剪裁

- 預設：**兩件式短上衣＋短裾**。胸前或背後鑽空可留，當錯開項，不是每張都要。
- 材質對上聖殿：槍灰、黑鐵、霜銀、接縫少量青銅。不是宇治深藍外套，不是和服正裝。
- 相鄰小時至少錯開：衣服色、襪色、剪裁、髮、妝、姿勢、視線。

### 絲襪美腿是主體，不是點綴

腿必須在 16:9 裡讀得清楚：人拉近、腿走畫面長邊或佔前景。

**襪色（可配場景）：** 每小時選一種，寫進該槍提示，不要 24 小時鎖同一套。

| 選擇 | 看得見的成功 | 不要畫成 |
|---|---|---|
| 膚色乾透 | 對上**同一張**已露出的上臂或腰；一層乾尼龍貼膚光；瞇眼像裸腿 | 米色塗層、灰膜 |
| 黑 | 仍看得出腿型與膝後皺；鞋口有襪緣進去。後視可選：襪面一路貼到臀下弧（`12` v1a／v1b／v2） | 實心西褲、乳膠亮面；襪在大腿中段卡住、下弧變裸 |
| 配該小時場景 | 對上**這一廳**已在的色：霜藍源床、槍灰／霜銀、接縫琥珀、渦緣暗石墨……襪面跟廳是同一套光 | 宇治那種抹茶／紫根食物染色；不要無故彩虹 |

鞋口要有襪緣、膝後要有皺，用來證明有穿。膚色槍用「腿對上腰／臂」當證人；黑與場景色用襪緣、膝皺、乾尼龍高光當證人。

**不透明褲襠（非必要）：** 正面走來、封閉下襬時，不必為了露出連褲襪補強褲襠去催開衩或貼肉色塊。`6` 已驗證：Pretty Polly 當第二參考會變成米色貼紙；催同色マチ會畫成油亮錯 T 縫或側髖缺口（`6-v4-paste`、`6-v9-gusset`、`6-v10-paste`）。側坐或背面臀下弧若自然看得見那一小塊同色較厚織片，可以留；不要為它犧牲場景與透膜。

禁：乳膠、濕油亮面（B）、小腿後中縫。直線劃過股底的錯 T 縫不如不畫（京都 `_trials/14-visible-gusset.jpg`）。生殖器級細節只在已寫明的小時：`13` 是膜下若隱若現；`19`–`20` 三角是與腰相同的裸膚。其餘小時停在該小時那一條界線，不提前跳到三角特寫。

### 膚色

淺、瓷白到淺東亞膚。臉、頸、手臂、腰同一套。上半身偏深、露出的腰／臂偏白是京都／宇治反覆修過的錯。腿跟不跟膚色走，看該小時選的襪：膚色乾透才對上腰／臂；黑或場景色可以跟膚不同。

### 構圖

人不能當一根豎線插在聖殿明信片中間。成功的是：

- 側坐臺沿／環緣／粒子床（一腿伸、一腿收，腿走長邊）
- 四分之三背面走遠／登階（臀線才入鏡）
- 朝鏡頭走來或從環門跨出（腿是主體，但**看不到臀下弧**）

鏡頭近一檔。兩側仍宜低細節，給桌面圖示留空，但人必須夠大。`6`–`11` 的兩側可以偏暗；`12`–`18` 兩側低細節但不能把人、地面、核心壓進黑裡。

## 12–18 的光（相對 6–11）

`6`–`11` 是暗石＋單點頂光，人與腿容易欠曝。從 `12` 起要**光源充足、不要太暗**：背／腿／臉、腳下地面、中景核心都曝光清楚。不是過曝白廳，不是舊 `12` 那種開闊山景白亭。

| 小時 | 光的地板 | 光的天花板 |

| `12`–`13` | 封閉淺石正午廳；拱頂開口的漫射光＋懸浮核心；人與地面清楚 | 牆不是死白；沒有山脈／天空佔滿畫面 |
| `14`–`15` | 仍足光，偏銀 | 不要回到地窖 |

### 鞋

預設日常黑色粗跟／中低跟，鞋口乾淨讓襪線進去。可變體：金屬色淺跟、繞踝帶。一次只改鞋，不要跟下襬綁在同一槍。不要無故變成細尖高跟。

## 產圖提示：身體界線，不是服裝類名

模型會把 `short` / `mini` / `再短 10cm` / 單獨的 `5 denier` 映射成安全時裝預設，度量不會動。意圖是短裾美腿，提示裡要寫**碰到哪一條身體線**。

每次生成只改**一個**可見度量。先寫參考圖哪裡不對，再寫新的可見結果。有上限也要有露出下限。姿勢與鏡頭必須讓那條界線入鏡。

```
ONE CHANGE: [delta].
The current [feature] [wrong landmark].
The new [feature] [success landmark].
Still [ceiling so it does not overshoot].
```

| 不要寫 | 要寫 |
|---|---|

## 已驗證流程（沿用宇治／京都）

1. 覆寫前先備份現況：`cp --update=none N.jpg _trials/N-before-character.jpg`（symlink 先拆成獨立檔再備份）。
2. 從零產圖 `16:9`。第一槍允許場景＋人一起出。參考用文字寫聖殿材質，**不要**拿舊的遠景空景當構圖鎖（會把人縮掉或把碗城帶回來）。
3. 一次一個可見度量。修下襬／襪／鞋拆開。需要整層襪膜時，緊裁腿區產圖再羽化貼回 4K；不要局部像素染色。
4. 寫入正式檔：

```bash
convert "$SRC" -filter Lanczos -resize '3840x2160^' -gravity center \
  -extent 3840x2160 -colorspace sRGB -quality 92 \
  "$DEST/_trials/${trial}.jpg"
cp "$DEST/_trials/${trial}.jpg" "$DEST/${hour}.jpg"
```

5. `identify` 確認 `3840×2160` sRGB。未接受的槍只留 `_trials/`。
6. 不要跑會改桌布的 `./test.sh -s liquid-geo-temple`，除非使用者明確要求。
