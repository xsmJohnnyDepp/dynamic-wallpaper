# 人物造型與產圖 brief（日後必讀）

這組搬的是 `neon-dystopia` 的**人物語法**，不是 2049 的城、霧或 OS。地點維持真實京都地標；人物是原創成年女性。一張一個造型，不演電影角色、不仿可辨識藝人／藝伎臉。

24 小時都是獨立 `3840×2160` sRGB JPG。**不是每小時都有人。** 遠景、尺度在城或構圖會讓人縮成小點的小時，留空或換地點，不要硬塞。

試作與被替換的定稿在 `_trials/`（本機檔案庫；覆寫正式檔前先備份）。褲襪商品參考在 `images/neon-dystopia/_trials/`：`pp-10d-beige-side-a.jpg`、`16-C-drysheer.jpg`（乾透 C，不要油亮 B）。

## 不可拆的人物語法

### 剪裁

- 預設：**兩件式短上衣＋短裾**。胸前或背後鑽空可留。
- 和服可以嘗試，但要**短裾＋細帶**，不是曳地正裝、不是寬花嫁帶、不是藝伎妝。交領、金邊、左衽交疊可以當「和服構造」，長度仍用身體界線寫。
- 大衣只留給真的在「穿過空間」的站姿。京都這組目前沒有大衣小時。
- 無袖、大開背、側開是後期才用，用來跟前幾張的交領短袖錯開。

### 絲襪美腿是主體，不是點綴

腿必須在 16:9 裡讀得清楚：人拉近、腿走畫面長邊或佔前景。遠景加人會失敗。

已驗證的可見規格（**不要只寫 denier 數字**）：

| 光 | 目標可見結果 | 參考 |
|---|---|---|
| 日／暖光 | 腿色對上露出的腰或手臂；瞇眼幾乎像裸腿；小腿只有一層乾尼龍高光 | Pretty Polly 米色 10 denier **乾透 C**；再透則接近 5 denier |
| 要更透 | 與上臂／腰同一膚色；不是米色塗層、不是灰膜 | 用**同一張裡已露出的上臂或腰**當第二參考，不要用另一張的腿硬套 |
| 夜／冷光 | 透膚黑：還看得到皮膚，不是實心黑褲 | `16`、`20` |
| 夜前可變 | 極薄酒紅／煙灰紗可以試，但夜景很容易畫成不透塗層 | `19` 後來改成對上上臂的透膚 |

**禁：** 實色象牙、乳膠、濕油亮面、小腿後中縫、迷你裙下露出不透明褲襠當「有穿」的證明。

**褲襠 T 縫／菱形マチ：** 極透時模型常畫錯（直線劃過股底，不像沿臀溝走的織片）。錯的縫不如不畫。正式稿以「腿色＝腰／臂、小腿乾高光」證明有穿。`14` 試作 `_trials/14-visible-gusset.jpg` 是反例。

### 膚色

淺、瓷白到淺東亞膚。臉、頸、手臂、腰、腿同一套。上半身偏深、腿偏白是這組反覆修過的錯。

### 構圖

人不能當一根豎線插在明信片中間。成功的是：

- 側坐台沿（一腿伸、一腿收，腿走長邊）
- 四分之三背面靠欄／走遠／登階（臀線才入鏡）
- 朝鏡頭走來或從門檻跨出（腿是主體，但**看不到臀下弧**）

站姿留給「穿過空間」的小時。鏡頭近一檔。

### 鞋

預設日常黑色粗跟／中低跟，鞋口乾淨讓襪線進去。不要無故變成細尖高跟或木屐。

已用過的變體：`14` 繞踝帶中跟；`16` 試過腳背瑪莉珍；`18` 裸色淺跟。一次只改鞋，不要跟下襬綁在同一槍。

### 密度與錯開

一張一個原創成年女性。相鄰人物小時必須在**衣服色、剪裁、髮、妝、姿勢、視線、襪色**至少錯開數項。回眸看鏡頭極容易撞型（`12`、`16` 已用；`18`–`20` 後來都鎖到場景地標）。

## 產圖提示：身體界線，不是服裝類名

模型會把 `short` / `mini` / `kimono` / `再短 10cm` / 單獨的 `5 denier` 映射成安全時裝預設，度量不會動。

每次生成只改**一個**可見度量。先寫參考圖哪裡不對，再寫新的可見結果。有上限也要有露出下限。姿勢與鏡頭必須讓那條界線入鏡。

```
ONE CHANGE: [delta].
The current [feature] [wrong landmark].
The new [feature] [success landmark].
Still [ceiling so it does not overshoot].
```

| 不要寫 | 要寫 |
|---|---|
| `shorten the hem 10 cm` | 現在下襬在大腿中段、臀部全蓋住；新下襬露出臀部下弧與臀溝，布料仍蓋住臀部上半 |
| `short kimono` / `mini` | 交疊裾的構造 **加上** 下襬要碰到的身體線 |
| `ordinary heel` / `4–5 cm` | 日常粗跟，明顯短於參考圖的細尖高跟 |
| 單獨 `5 denier` | 腿對上已露出的腰／上臂；只有一層乾尼龍高光；瞇眼像裸腿 |
| 只有 `still covering, not underwear` | 那是天花板；還要寫露出下限 |

### 姿勢決定看不看得見

| 目標 | 鏡頭 |
|---|---|
| 臀下弧／背後鑽空 | 站立、四分之三背面或背面 |
| 褲襪透度 | 腿要大；對上腰或上臂 |
| 步幅 | 側面或四分之三，不要鎖死正面站樁 |
| 側坐 | 看不到臀線 |
| 正面走來 | 看不到背與臀下弧 |

### 開衩不是一個數字

交疊裾的開衩有三條獨立界線。模型會捆在一起：內側大腿開很高時，常順便變出長側片；下襬一短，又收成封閉迷你裙加一點側髖缺口。

| 界線 | 用身體線寫 | 不要寫成 |
|---|---|---|
| 開口路徑 | 沿**前腳內側大腿**往上爬 | `high slit` / `side slit` |
| 頂點 | 髖摺、腰帶下方 | `open higher` |
| 側片下襬 | 最長片停在髖摺／座面中段／臀下弧 | `shorten the slit panel` |
| 鼠蹊三角 | 若不需要覆蓋，明講**可以不蓋** | 暗示長片必須留下才能「開高」 |

`13` 的對照：`_trials/13-indigo-gallery.jpg` 看起來高，是因為開口走內側大腿，不是因為鼠蹊三角被布蓋住。只寫短下襬會變成側髖小開衩。

短下襬時要明講：可保持內側大腿 V 字開口；外蓋長片不需要；鼠蹊三角可以不蓋。

## 臉、髮、妝

不仿特定藝人。可借**產地類型**當輪廓，再疊現代（令和）妝，不要平成盛妝、不要三白娃娃臉、不要韓系厚妝。

| 類型 | 輪廓（參考用，原創臉） | 本組使用 |
|---|---|---|
| 秋田美人 | 色白、臉較圓、眼較柔、低髻＋瀏海 | `14` 優先（秋田 ≥ 京 > 博多） |
| 京美人／瓜實臉 | 面長卵型、頰到頜平滑、切れ長奧雙、小直鼻、漆黑髮 | `10` 重畫臉：令和薄膜、平行眉、血色在顴骨上 |
| 博多美人 | 五官對比較清楚、長直髮、潮流感 | `14` 試作 `_trials/14-hakata.jpg`，正式稿未採用 |
| 令和妝 | 薄膜底、平行眉、細眼線、血色在頰的**高處**、唇色留在唇線內 | 眼下不要畫深色／腫塊（會讀成瘀青） |

現代妝重點：透膚底、內頰血色、水光眼、幾乎不畫黑眼線、霧玫瑰或裸色唇。髮以漆黑為主；`18` 用淺褐長波浪來錯開。

**修臉：** 眼眶錯位、雙層眼皮、「左臉像被打過」不要在舊臉上補丁。整張頭重畫，視線鎖在場景地標（`10` 是低頭看苔徑，不是看鏡頭）。庭園側是受光面，應該更亮更平，不該更暗更腫。

**唇：** 莓色／口紅只在唇線內。下巴乾淨。`19` 近景曾把唇色畫成下巴藍黑塊。

**手臂：** 一隻手只做一件事。`20` 曾出現一隻手臂又扶燈柱又環抱；應寫「左手是唯一碰到燈柱的手；右手垂在右側」。

## 已驗證流程

1. 先 `cp --update=none N.jpg _trials/N-original.jpg`。
2. 產圖 `16:9`，參考正式檔當場景／姿勢，度量用身體界線；一次一項。
3. 需要對齊已成功的下襬或透度時，用**兩張參考**：第一張 KEEP 場景姿勢，第二張只 copy 那一條界線。
4. 寫入正式檔：

```bash
convert "$SRC" -filter Lanczos -resize '3840x2160^' -gravity center \
  -extent 3840x2160 -colorspace sRGB -quality 92 \
  "$DEST/_trials/${trial}.jpg"
cp "$DEST/_trials/${trial}.jpg" "$DEST/${hour}.jpg"
```

5. `identify` 確認 `3840x2160` sRGB。未接受的槍只留在 `_trials/`。

## 過濾器與失敗模式

- 寫「不穿裙子只穿褲襪」「露側乳」「生殖器級褲襠縫」容易 `400` 或畫壞。有上限也要有布料仍蓋住的天花板。
- `high slit` 會變成側髖缺口；短下襬會把開衩關起來。分開寫路徑／頂點／側片。
- 用另一張的腿當透度參考，常變成裸腿或實色襪。改對**同一身體的上臂或腰**。
- 改臉、改妝、改下襬時，模型會順便把視線轉回鏡頭。要明寫看哪個場景地標。
- 局部修壞掉的半邊臉會留下「兩張臉拼在一起」。整頭重畫較穩。
- 場景不適合近人就換真實地點（`11` 市場→水路閣，`19` 遠園→貴船），或跳過（`15`、`17`）。
